# Changelog

All notable user-visible changes to the GoatCounter TOS application package.

## 2.7.0-1 — 2026-11-14

### Added
- First release. GoatCounter (`arp242/goatcounter:2.7.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8131 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/goatcounterdocker/`.
